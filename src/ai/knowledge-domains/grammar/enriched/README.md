# Enriched Grammar Vocabulary

This directory contains enriched grammar vocabulary data imported from ZacAi-3.0.0 repository. These files provide comprehensive grammatical concepts, rules, and examples.

## Files

- **grammar.json** - Core grammar vocabulary
- **grammar_2.json** through **grammar_7.json** - Extended grammar concepts and rules

## Structure

Each grammar file contains detailed grammatical information including:
- Grammar terms and concepts
- Definitions and explanations
- Usage examples
- Related grammatical concepts
- Language rules and patterns

## Usage

These enriched grammar files support:
- Grammatical analysis and checking
- Natural language generation with proper grammar
- Language understanding and parsing
- Educational features for grammar learning
