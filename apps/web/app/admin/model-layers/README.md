# Admin Model Layers

## Overview
Manages and visualizes all model layers, including context enhancers, classifiers, and optimizers. Supports model inspection and configuration.

## Features
- Model layer visualization
- Layer configuration and tuning
- Integration with model registry

## File Reference
- `[model]/` – Dynamic model routes
- `context-enhancer/`, `domain-router/`, etc. – Specialized model layer modules
- `page.tsx` – Model layers overview UI
