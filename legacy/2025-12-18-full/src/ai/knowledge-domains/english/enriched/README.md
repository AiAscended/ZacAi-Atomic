# Enriched English Vocabulary

This directory contains enriched English vocabulary data imported from ZacAi-3.0.0 repository. These files provide comprehensive English language vocabulary with detailed definitions, examples, and linguistic metadata.

## Files

- **alphabet.json** - Comprehensive alphabet and character vocabulary
- **vocab_seed_1.json** through **vocab_seed_15.json** - General English vocabulary seeds covering common words and phrases

## Structure

Each vocabulary file contains an array of word objects with rich linguistic information including:
- Word definitions
- Parts of speech
- Example usage
- Synonyms and antonyms
- Pronunciation
- Frequency ranking
- Related words
- Language level (A1, A2, B1, B2, C1, C2)

## Usage

These enriched vocabulary files support:
- Natural language understanding
- Text generation with proper vocabulary usage
- Language learning and education features
- Semantic analysis and contextual understanding
