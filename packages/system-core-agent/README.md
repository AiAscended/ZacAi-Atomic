# @zacai/system-core-agent

Scaffold for Phase 7: System Core Agent.

This package will host the AI-driven orchestration agent responsible for recommending and (with safeguards) executing recovery and orchestration actions.

Current status: scaffold only.

Planned functionality:
- Policy engine and safety layer
- Agent decision API
- Integration with `@zacai/system-core` and dashboard `/api/ai`
- Audit logging for all agent actions
